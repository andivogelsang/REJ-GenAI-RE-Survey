# Qualitative codebook

`round1/coding-benefits-drawbacks_V1.xlsx` — the thematic coding schema used
for round 1's open-text questions (14 themes / 52 codes, as described in the
paper's Analysis Strategy). Sheets:

- `codebook` — the code list with per-RE-phase frequency counts.
- `elicitation`, `analysis`, `specification`, `validation`, `management` —
  code assignments per participant response, one sheet per RE phase.

Sourced from the round-1 Zenodo deposit (10.5281/zenodo.18207273).

A `round2/` coding pass covering the second wave of open-text responses will
be added here once complete.
